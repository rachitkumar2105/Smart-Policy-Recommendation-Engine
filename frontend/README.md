# SPRE Frontend

React + TypeScript SPA (Vite) for the Smart Policy Recommendation Engine. See the
repo root [README.md](../README.md) for full setup, architecture, and testing docs.

```bash
npm install
npm run dev      # http://localhost:5173, expects the backend on :8000
npm run test     # Vitest
npm run lint     # oxlint
npm run build    # production build to dist/
```
